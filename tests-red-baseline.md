Each platform's suite is run end-to-end; pass/fail/ignored totals land here so
the fix backlog is a `git diff`.

## How to read changes

- **passed ↑**: new tests written and passing, or a RED test was fixed.
- **failed ↑**: a new spec gap was tested (good — more coverage), or a regression.
- **failed ↓**: a spec gap was fixed. Verify via the commit that closed it.
- **ignored ↑**: a test was parked with a specific follow-up note (test-harness
limitation, not a lost test). Search the test source for `#[ignore` to find
the reason.
- **passed ↓ without a matching failed ↑**: investigate — a test was likely
deleted or renamed.
